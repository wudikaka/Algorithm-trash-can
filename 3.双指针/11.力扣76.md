给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。  

示例：  
输入：s = "ADOBECODEBANC", t = "ABC"  
输出："BANC"  
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。  
  
思路：  
最开始的准备工作：用need数组记录字符串t中各个字符出现次数，整数needcount记录t中字符种类，用范围for循环遍历need数组初始化并且计算有多少种字符串，用have数组记录有当前窗口中t需要的各个字符有多少个，记录已有的种类数量。  
  
寻找记录部分：
每次大循环右边界都必定右移一次，把右边界上的字符放到need数组中检查是否t字符串需要，如果需要则have数组的对应字符记一个，顺便立马检查是否have数组和need数组中对应位置的数相等，检查是否已经达到目标数量，有则记种类加一，这里有两个设计巧思，第一，它把这个已有种类加一的检查放在了need[c]>0内，只要记该处是t字符串需要的字符时才会进行判断，节省时间；第二，它这是==而不是>=，若已经达到目标，但往后的区间内还有该字符，此时可能会导致再次让已有的种类加一。  
  
滑动窗口的缩小边界部分：
判断条件：已有种类和需要种类一致，这样就不用再次检查两边数组了，时间率很高，并且再加上left<=right条件保证安全，使得左边界不可能超过右边界。  
更新最小长度：如果区间长度小于上次记录的最小长度，就重新记一次，并且记这次达成条件的子串起始位置，方便后来查找。  
移动左边界：如果左边界上的字符是t需要的字符，移动时就要减去have数组中已拥有的该字符数量，因为进入缩小边界部分只可能是已有字符种类数量>=目标字符种类数量，若是>，减去这个字符无影响，但若是=，可能会导致该区间的子串不再满足条件，则让已有字符种类数量减一。  
所有准备完毕就让左边界右移，至此一个大循环结束，进入下一个循环。最后返回部分，如果minLen还是初始化时的值INT_MAX，就返回空字符串，否则返回从start开始往后minLen长度的s的子串

感受：牛逼，要是多练几道应该乱杀这种题，但没太多时间

```cpp
class Solution
{
public:
    string minWindow(string s, string t)
    {
        // 用数组代替哈希表（字符的 ASCII 范围是 0-127）
        int need[128] = {0}; // 记录 t 中每个字符还需要多少
        int needCount = 0;   // 记录 t 中不同字符的种类数

        // 初始化 need 数组
        for (char c : t)
        {
            if (need[c] == 0)
                needCount++; // 遇到新字符，种类数+1
            need[c]++;
        }

        int left = 0, right = 0;
        int have[128] = {0}; // 记录当前窗口中有需要的字符的数量
        int haveCount = 0;   // 记录当前窗口已经满足了多少种字符

        int minLen = INT_MAX;
        int start = 0; // 记录最短子串的起始位置

        while (right < s.length())
        {
            char c = s[right];

            // 如果这个字符是 t 需要的
            if (need[c] > 0)
            {
                have[c]++;

                // 如果这个字符的数量已经达到要求
                if (have[c] == need[c])
                {
                    haveCount++;
                }
            }

            // 当所有字符都满足要求时，尝试缩小左边界
            while (haveCount == needCount && left <= right)
            {
                // 更新最小长度
                if (right - left + 1 < minLen)
                {
                    minLen = right - left + 1;
                    start = left;
                }

                // 移动左边界
                char leftChar = s[left];
                if (need[leftChar] > 0)
                {
                    if (have[leftChar] == need[leftChar])
                    {
                        haveCount--;
                    }
                    have[leftChar]--;
                }
                left++;
            }

            right++;
        }

        return minLen == INT_MAX ? "" : s.substr(start, minLen);
    }
};
```
