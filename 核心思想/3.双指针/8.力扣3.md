给定一个字符串s，请你找出其中不含有重复字符的最长子串的长度。  

***滑动窗口***

我的方法：  
子串长度len先从最大长度(母串本身)开始，逐渐减小到0。每个循环都用长为len的窗口不停检查是否无重复，范围为[l , l+len)左闭右开，是为了配合STL容器的左闭右开设计原则。  
比如，在数值方面，总元素个数为size，子串长度为len；在索引方面，最大索引的后一个是size，窗口右边界的后一个是l+len，都可以用开区间。  
服务于STL的部分为提取子串部分，要传入的是起始位置迭代器和提取长度，但这里的长度也是左闭右开思想，因为实际上提取到的部分是[pos , pos + len - 1]，即[pos , pos + len)  


```cpp
class Solution
{
public:
    int lengthOfLongestSubstring(string s)
    {
        int size = s.size(); // 全部下标0~size-1
        int len = size; //  最大子串长为len，即自身

        while (len > 0) // len代表子串长度
        {
            int l = 0; // 左边界
            while (l + len <= size) // 这里的l+len是右边界，开区间，正好对应字符串右边界的size开区间
            {
                int r = l + len;// 右边界 左闭右开 [l,r)
                string sub = s.substr(l, len);
                sort(sub.begin(), sub.end());

                bool hasDuplicate = 0; // 没有重复
                for (int i = 1; i < len; i++)
                {
                    if (sub[i] == sub[i - 1])
                    {
                        hasDuplicate = 1; // 出现一次重复
                        break;
                    }
                }
                if(!hasDuplicate) // 没有重复
                {
                    return len;
                }
                l++; // 窗口后移
            }
            len--; // 缩小子串长度
        }
        return 0;
    }
};
```

官方的方法：
先创建一个数组用来存放所有字符最后一次出现的位置，因为ASCII值只有128个，所以就初始化128个-1。  
窗口左右边界一开始都在0，先让右边界探索，右边界取到某个字符，找找lastIndex中对应该字符最后一次出现的位置，若不是-1则说明以前出现过，这里用左边界位置检查，如果>=left，就说明在目前窗口中已经出现过它了，这时候让左边界移动到这个字符上一次出现的位置的后面一个，再用右边界探索到的位置更新一下这个字符最后一次出现的位置，此时窗口更新完毕。每轮窗口更新之后都要用max函数检查一下之前和现在哪个更大，取更大的一个记录。  
大概的理解就是：在保持左边界不动的情况下右边界持续扩展，尽可能大，若遇到有重复的则左边砍掉一部分左边界从以前有过该重复元素的右边继续  

```cpp
class Solution
{
public:
    int lengthOfLongestSubstring(string s)
    {
        vector<int> lastIndex(128, -1); // ASCII 字符最后出现的位置
        int maxLen = 0;
        int left = 0; // 窗口左边界

        for (int right = 0; right < s.size(); right++)
        {
            char c = s[right];

            // 如果字符重复且在窗口内，移动左边界
            if (lastIndex[c] >= left)
            {
                left = lastIndex[c] + 1;
            }

            // 更新字符最后出现的位置
            lastIndex[c] = right;

            // 更新最大长度
            maxLen = max(maxLen, right - left + 1);
        }

        return maxLen;
    }
};
```
