
给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

***对撞指针***

思路：按理来说最大值平方后还是最大值，直接照常放过去即可，但这里可能有很小的负数，平方后可能会变成最大值，所以需要比较一下两边哪个平方后最大，然后放入，所以想到了双指针，由于中间越靠近0的地方平方越小，所以想到要往中间收缩，因此用对撞双指针。

```cpp
class Solution
{
public:
    vector<int> sortedSquares(vector<int> &nums)
    {
        int l = 0;
        int r = nums.size() - 1;
        int k = nums.size() - 1;
        vector<int> result(nums.size());

        while (l <= r)
        {
            if (nums[l] * nums[l] > nums[r] * nums[r])
            {
                result[k] = nums[l] * nums[l];
                --k;
                ++l;
            }
            else
            {
                result[k] = nums[r] * nums[r];
                --k;
                --r;
            }
        }
        return result;
    }
};
```
