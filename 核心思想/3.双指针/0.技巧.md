1. 有序数组/链表 → 优先想双指针  

- 特征：数据有序（或可排序）  
典型应用：  
两数之和、三数之和  
平方后排序  
合并两个有序数组  
移除元素（有序版）  

- 判断逻辑：看到“有序”两个字，脑子里第一反应就是“能不能用双指针”。  

2. 子数组/子串问题 → 优先想滑动窗口（同向双指针）  

- 特征：求连续区间的某个性质（最长、最短、恰好、包含某条件）  
典型应用：  
最长无重复子串  
最小覆盖子串  
和为K的子数组  

- 判断逻辑：问题里出现“连续子数组/子串”，并且需要动态维护区间 → 滑动窗口。  

3. 数组去重/原地修改/链表环 → 优先想快慢指针  

- 特征：  
去重（原地）  
移动零  
链表环检测、找环入口  
找链表中点、倒数第K个节点  

- 判断逻辑：需要在O(1)空间下修改数组/链表结构 → 快慢指针或同向双指针（一个遍历、一个记录位置）。
