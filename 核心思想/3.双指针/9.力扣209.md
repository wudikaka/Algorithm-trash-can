给定一个含有 n 个正整数的数组和一个正整数 target   
找出该数组中满足其总和大于等于 target 的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] ，并返回其长度。如果不存在符合条件的子数组，返回 0   

***滑动窗口***


我的解法：
因为要找子数字，一堆元素连续的，所以想到滑动窗口  
让左右指针都从0开始，右指针不停右移扩展区间，因为每次都是右指针先遇到新的元素，所以设定的sum由右指针累加，当遇到sum >= target，就让左指针右移尝试收缩区间，收缩区间后会丢失元素，这时候要sum -= nums[left]，去除原本左指针的元素。由于刚收缩一次形成新的区间时，会因为立马进入下一个for循环的 right++ 而又扩展一次区间，没有检查刚刚收缩时是否满足sum >= target，需要让right保持不变，则用right--来抵消for循环的right++。由于sum是累加的，上一轮已经累加过nums[right]，如果保持不变，下一轮又加一次，所以要sum -= nums[right]，去除即将重复的元素。  
要用min函数找最小的minLen，初始化就要用最大值，由于需要条件判断是否执行过if(sum >= target)，则令minLen为一个不可能得到的值，即size + 1


```cpp
class Solution
{
public:
    int minSubArrayLen(int target, vector<int> &nums)
    {
        int size = nums.size();
        int left = 0;
        int sum = 0;
        int minLen = size + 1;

        for (int right = 0; right < size; right++)
        {
            sum += nums[right];

            // 当窗口和满足条件时，不断缩小左边界
            if (sum >= target)
            {
                // 更新最小长度
                minLen = min(right - left + 1, minLen);
                // 缩小窗口，左边界右移，减去对应的值
                sum -= nums[left];
                left++;
                // 保持右边界不变，抵消for循环的right++和下一轮的累加
                sum -= nums[right];
                right--;
            }
        }

        if (minLen == size + 1)
            return 0;
        else
            return minLen;
    }
};
```

优化版：
①if部分的 ++ -- 有点繁琐了，本质上就是为了能检测一下左边界收缩后新数组是否满足sum >= target，此时如果用while循环就可以避免立即进入for循环的下一次循环，执行一次收缩后会自动再判断sum >= target
②return部分的if-else也麻烦了，可以直接用三目运算符

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0;
        int sum = 0;
        int minLen = INT_MAX;
        
        for (int right = 0; right < nums.size(); right++) {
            sum += nums[right];
            
            // 当窗口和满足条件时，不断缩小左边界
            while (sum >= target) {
                // 更新最小长度
                minLen = min(minLen, right - left + 1);
                // 缩小窗口，左边界右移，减去对应的值
                sum -= nums[left];
                left++;
            }
        }
        
        return minLen == INT_MAX ? 0 : minLen;
    }
};
```
