车上最初有 capacity 个空座位。车 只能 向一个方向行驶（也就是说，不允许掉头或改变方向）
给定整数 capacity 和一个数组 trips ,  trips[i] = [numPassengersi, fromi, toi] 表示第 i 次旅行有 numPassengersi 乘客，接他们和放他们的位置分别是 fromi 和 toi 。这些位置是从汽车的初始位置向东的公里数。
当且仅当你可以在所有给定的行程中接送所有乘客时，返回 true，否则请返回 false。

***一维差分***

- 自己的答案：
构建个不是完全意义上的差分数组，然后原地求前缀和还原数组，正常的差分数组是n + 1个元素，我构建这个是n个元素，当区间增值时的R+1部分遇到尾边界时不-=val，因为这个本身就是告诉从R+1开始不用增val了，后面都没有元素了自然就不用了。  
后面直接暴力检查。  
这里最阴的是：to处下车了，所以一批人在车上是[ from , to - 1 ]。  
但问题是，这里并没有要求我返回修改后的数组，所以我这走弯路了。  

```cpp
class Solution
{
public:
    bool carPooling(vector<vector<int>> &trips, int capacity)
    {
        vector<int> diff(1000);
        for (auto &trip : trips)
        {
            int numsPassengers = trip[0];
            int from = trip[1];
            int to = trip[2];

            diff[from] += numsPassengers;
            if (to < 1000)
                diff[to] -= numsPassengers;
        }

        for (int i = 1; i < 1000; i++)
        {
            diff[i] += diff[i - 1];
        }

        for (int i = 0; i < 1000; i++)
        {
            if (diff[i] > capacity)
                return false;
        }

        return true;
    }
};
```

- 官方的答案：
先遍历一遍找出最大的to，然后用这个构建个to_max + 1大的差分数组。  
对每个位置求前缀和，赋值给count，表原数组修改后该位置的值，然后一直比较，和我的想法差不多

```cpp
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
        int to_max = 0;
        for (const auto& trip: trips) {
            to_max = max(to_max, trip[2]);
        }

        vector<int> diff(to_max + 1);
        for (const auto& trip: trips) {
            diff[trip[1]] += trip[0];
            diff[trip[2]] -= trip[0];
        }

        int count = 0;
        for (int i = 0; i <= to_max; ++i) {
            count += diff[i];
            if (count > capacity) {
                return false;
            }
        }
        return true;
    }
};
```
