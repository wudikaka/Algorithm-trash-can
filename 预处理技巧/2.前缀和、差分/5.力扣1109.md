这里有 n 个航班，它们分别从 1 到 n 进行编号。
有一份航班预订表 bookings ，表中第 i 条预订记录 bookings[i] = [firsti, lasti, seatsi] 意味着在从 firsti 到 lasti （包含 firsti 和 lasti ）的 每个航班 上预订了 seatsi 个座位。
请你返回一个长度为 n 的数组 answer，里面的元素是每个航班预定的座位总数。

- 示例：
输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
解释：
航班编号        1   2   3   4   5
预订记录 1 ：   10  10
预订记录 2 ：       20  20
预订记录 3 ：       25  25  25  25
总座位数：      10  55  45  25  25
因此，answer = [10,55,45,25,25]

***一维差分模板***

自己的暴力法：

```cpp
class Solution
{
public:
    vector<int> corpFlightBookings(vector<vector<int>> &bookings, int n)
    {
        vector<int> ans(n);
        int size = bookings.size();
        for (int i = 0; i < size; i++)
        {
            for (int j = bookings[i][0] - 1; j <= bookings[i][1] - 1; j++)
            {
                ans[j] += bookings[i][2];
            }
        }
        return ans;
    }
};
```

- 力扣官方答案：
创建差分数组nums，因为初始数组全是0，所以在修改区间元素之前不用初始数组来初始化差分数组。  
用booking遍历一遍bookings，因为bookings中每个数组的前两个值是位序而不是下标，所以拿每次遍历bookings得到的booking数组中第0个元素再减去1表示增加值的起始位置下标，第1个元素表示增加值结束位置下标的后一位，因为差分修改值的公式是L~R增加val，则diff[L]增val，diff[R+1]减val。  
到最后则对差分数组进行前缀和，还原初始数组。可以每轮修改值都可以叠加在同一个差分数组上。  
注意，这里并不是标准意义上的差分数组，这里为了方便最后直接把差分数组nums当答案返回，设定了元素数为n而非n+1，如果是vector<int> nums(n+1)，最后一个元素是0。  
```cpp
class Solution
{
public:
    vector<int> corpFlightBookings(vector<vector<int>> &bookings, int n)
    {
        vector<int> nums(n);
        for (auto &booking : bookings)
        {
            nums[booking[0] - 1] += booking[2];
            if (booking[1] < n)
            {
                nums[booking[1]] -= booking[2];
            }
        }
        for (int i = 1; i < n; i++)
        {
            nums[i] += nums[i - 1];
        }
        return nums;
    }
};
```
