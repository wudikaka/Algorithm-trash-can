一、什么时候用前缀和？
核心特征：快速、多次查询某个连续段的汇总信息（和、积、异或、平均值等）

常见问法：
“求 [L, R] 区间内的和 / 乘积 / 异或值”
“求有多少个子数组满足某个条件”（如和为 K、和能被 K 整除、奇数个数为某值等）
“求所有子数组的某个统计量之和”

典型包装：
包装后的题目	                            本质
“求所有连续子数组的和的平方再求和”	    前缀和预处理，然后枚举
“求有多少个区间内0和1的数量相等”	    把0看作-1，求区间和为0（前缀和+哈希表）
“求最长连续子数组使得和能被K整除”	    前缀和+同余+哈希表

判断技巧： 子数组 / 连续区间 / 区间内 ，大概率是前缀和。

二、什么时候用差分？
核心特征：多次对连续区间进行相同的批量操作（加一个值、减一个值等），最后只关心最终状态。

常见问法：
“对 [L, R] 区间内的每个数加上 val，最后问每个数是多少”
“经过多次区间操作后，求最大值/最小值/满足条件的个数”
“问能否通过区间加操作将数组变成目标数组”

典型包装：
包装后的题目	                                         本质
“航班预订统计，每次给一段航程加座位”	              区间加，最后查询每个航班座位数
“拼车，每次在区间内上下车”	                         区间加（乘客数），判断是否超载

判断技巧： 对区间内所有元素 / 每一段都加上减去同一个值 / 最后查询判断，大概率是差分。
