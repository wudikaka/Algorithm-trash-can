
核心思想：每次外循环把数组分为已排序、将放最小值和未排序三部分，在未排序区域中找出最小值放到将放最小值的位置上，然后下一轮

- ①i代表已排序区域的边界，左边都是排好的，i位置上是准备放最小值的，右边都是没排的。  

- ②若最小值下标还是i，说明右边区域没有比nums[i]小的；若不是，说明右边区域有更小的，要交换位置，把它放到本轮外循环要放最小值的位置。  

当交换成本很高时（比如元素是大对象），选择排序有优势  

```cpp
void selectionSort(vector<int>& nums)
{
    int n = nums.size();

    
    for (int i = 0; i < n - 1; i++)
    {
        int minIndex = i; // 假设最小值的下标

        // 在未排序区域 [i+1 , n-1]中找最小值
        for (int j = i + 1; j < n; j++)
        {
            if (nums[j] < nums[minIndex])
            {
                minIndex = j;
            }
        }

        // 如果最小值不在位置i，交换
        if (minIndex != i)
        {
            swap(nums[i], nums[minIndex]);
        }
    }
}
```
