
核心思想：每轮循环像冒泡一样把最值往后传递

- ①这里每次循环都是i < n - 1，是因为下面交换部分是 j 和 j + 1,防止j + 1越界。  

- ②内层循环每轮把能找到最大的元素用冒泡的形式逐渐传递到最后，因为最大的放到最后一个了，下一轮就不用看这位置，进行第0(i=0)轮时，还未传递最大的数，进行第1轮(i=1)时，有一个最大元素，可以发现i为几，后面就传递了几个元素，因此内层循环在外层的第i轮时进行最大轮数要减去i。  

- ③内层循环若出现一轮未进行交换，说明都排好了，可以结束。  

```cpp
// 升序
void bubbleSort(vector<int>& nums)
{
    int n = nums.size();

    // 外层循环
    for (int i = 0; i < n - 1; i++)
    {
        bool ifSwap = 0;

        // 内层循环
        for (int j = 0; j < n - 1 - i; j++)
        {
            if (nums[j] > nums[j + 1])
            {
                swap(nums[j], nums[j + 1]);
                ifSwap = 1;
            }
        }

        // 若本轮没有交换，说明已有序，直接结束
        if(!ifSwap)
            break;
    }
}
```
