
核心思想：统计各种值元素出现次数，计算各种值元素的最后位置，从后往前填充

- 确定count范围：找最大值最小值锁定范围(为了让数组下标从0开始)，用数组的方式统计每个值出现的次数，此时count是元素出现次数。  

- 累加频次的作用：第一个元素的最后一个位置就是第一个元素的出现次数，第二个元素的最后一个位置就是第一和第二个元素的出现次数，第三个元素的最后一个位置就是第一二三个元素出现次数之和，以此类推，此时count是每个元素最后的位置。  

- 开始排序：从原数组最后一个元素开始，取元素，放到count中，找出它应该放在的位置，然后放到新数组中，放完之后更新一下count表示的该元素最后一个位置，让它往前移，因为这个位置已经放了一个该值元素了。  

- 为什么要反向填充？因为初始数组中可能有多个相同值，需要保证这些相同值之间的相对位置不变，这个count表示的是该元素的最后一个位置，为了让相对位置不变，就要先放相同值的后面一个元素。  

```cpp
vector<int> countingSort(vector<int> &arr) // [4, 2, 2, 8, 3, 3, 1]
{
    if (arr.empty())
        return arr;

    // 1. 找到数据范围
    int maxVal = *max_element(arr.begin(), arr.end()); // 8
    int minVal = *min_element(arr.begin(), arr.end());
    int range = maxVal - minVal + 1;

    // 2. 统计频次                      // count = [1, 2, 2, 1, 0, 0, 0, 1]
    vector<int> count(range, 0);       //       值  1  2  3  4  5  6  7  8
    for (int num : arr)
    {
        count[num - minVal]++;
    }

    // 3. 累加频次（得到每个值在结果数组中的最后一个位置）
    for (int i = 1; i < range; i++) // count = [1, 3, 5, 6, 6, 6, 6, 7] 
    {
        count[i] += count[i - 1];
    }

    // 4. 反向填充（为了保证稳定性）
    vector<int> result(arr.size());
    for (int i = arr.size() - 1; i >= 0; i--)
    {
        int val = arr[i];
        int pos = count[val - minVal] - 1;
        result[pos] = val;
        count[val - minVal]--;
    }

    return result;
}
```
