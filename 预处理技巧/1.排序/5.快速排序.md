
核心思想：利用递归，选一个基准，用两个指针从两端往中间找"错位"的数交换，直到所有比基准小的都在左边，比基准大的都在右边，然后左右两边重复这个过程，最后一定有序  

- ①调用时quickSortHoare(nums,left,right)，quickSortHoare函数的过程：执行到partitionHoare这部分，让数组的[left,pi]都<=基准pivot，[pi+1,right]都>基准pivot，这时候把它分成两部分了，往下执行到quickSortHoare(nums,left,pi);quickSortHoare(nums,pi+1,right);分别对两边再次进行定基准和拆分，跟上面的拆分结果一样，都是让pi左边<=，pi右边>，保持这样不停往深处递，直到数组被拆分到只剩一个元素，停止往深递，这个return什么都没返回，只是起终止作用。因为每次拆分都遵循一个规律：让数组尽可能有序，即把<=基准的放左边，>基准的放右边，执行到最后必定会完全有序。  

- ②partitionHoare函数的过程：取数组的中间元素为基准，用个一直循环的while(true)不停执行循环，i和j不停往中间收缩，在一轮中，i找到第一个>=基准pivot的，j找到第一个<基准pivot的，交换，目的是让左右两边分别是<=基准和>基准的元素，但边界还没确定，要到最后才知道。直到i>=j，说明在不相交的情况下已经没有满足条件的了，停止，返回j的位置，就是分界线，因为只要<=pivot，就通过swap放到j的左边，所以可以认为j左边都是<=pivot的元素，但因为这是do-while循环，先执行后判断，所以j会左移一个，因此j左边包括j自己位置上的元素都是<=pivot  

- ③边界处理：因为i左边都是 < pivot，循环结束后，若j在i左边，所以j左边都是 < pivot，因为只有nums[j] > pivot才左移j，所以j位置上的 <= pivot，所以[left,j]都 <= pivot；若j在i上，因为nums[i] < pivot才右移i，所以i位置上的 >= pivot，同时前面也推导过j位置上的<= pivot，因此j位置上的 == pivot，所以[left,j]都 <= pivot。因为j右边都是 > pivot，所以[j+1,right]都 > pivot  

```cpp
// Hoare分区法
// 分区函数：把数组分成 [<=pivot] 和 [>=pivot] 两部分
int partitionHoare(vector<int> &nums, int left, int right)
{
    int mid = left + (right - left) / 2;
    int pivot = nums[mid]; // 选中间的当基准
    int i = left - 1;
    int j = right + 1;

    while (true)
    {
        // 左边找第一个 >= pivot 的
        do
        {
            i++;
        } while (nums[i] < pivot);

        // 右边找第一个 <= pivot 的
        do
        {
            j--;
        } while (nums[j] > pivot);

        if (i >= j)
            return j;           // 指针相遇，返回分界点
        swap(nums[i], nums[j]); // 交换错位的元素
    }
}

void quickSortHoare(vector<int> &nums, int left, int right)
{
    if (left >= right)
        return; // 只剩一个元素，有序

    // 分区：返回分界点j，使得 [left, j] <= pivot，[j+1, right] > pivot
    int pi = partitionHoare(nums, left, right);

    // 分治：分别排序左右两边
    quickSortHoare(nums, left, pi);      // 排左边（包括pi位置的数）
    quickSortHoare(nums, pi + 1, right); // 排右边
}
```


实际运用：找出无序数组中第 k 小的元素，要求平均 O(n) 时间复杂度

解题思路：
①调用时quickSelect(nums,left,right,k)，先分区，随便取了一个基准，小于它的都在j左边，大于它的都在j右边，然后利用返回的这个j求出<=基准[left,j]的有多少个元素leftSize，若这个数比k大，那么第k小的数就在这个区间内，直接再次调用quickSelect往深处递，再次分成两个区间，重复上述步骤，判断在第k小的数在哪个区间；若比k小，则在右边的区间，但由于前leftSize小的必定在[left,j]内，所以在右边区间要找第k-leftSize小的元素，再次调用quickSelect，步骤同上。  

②由于每次不停拆分区间，都保证一直往初始数组中第k小的元素所在的部分缩小，所以直到最后只剩一个元素时，就是答案，这时候left==right，返回唯一的元素，一直往浅层归，回到最浅层，得到结果。  

③这个分区会把数组分为 <= pivot的[left,pi]和 >= pivot的[pi+1,right]，若数组只有两个元素，基准取到nums[0]，只可能pi = 0或1；若数组只有一个元素，基准取nums[0]，只可能pi = 0，因此不会越界

③partitionHoare函数的执行过程在之前快速排序部分有分析。  

```cpp
// Hoare分区法（选中间元素做基准）
int partitionHoare(vector<int> &nums, int left, int right)
{
    int mid = left + (right - left) / 2;
    int pivot = nums[mid]; // 选中间的当基准
    int i = left - 1;
    int j = right + 1;

    while (true)
    {
        // 左边找第一个 >= pivot 的
        do
        {
            i++;
        } while (nums[i] < pivot);

        // 右边找第一个 <= pivot 的
        do
        {
            j--;
        } while (nums[j] > pivot);

        if (i >= j)
            return j;           // 指针相遇，返回分界点
        swap(nums[i], nums[j]); // 交换错位的元素
    }
}

// 快速选择算法（Hoare分区版本）
int quickSelect(vector<int> &nums, int left, int right, int k)
{
    // 递归终止条件：区间只有一个元素
    if (left == right)
        return nums[left];

    // 分区，得到分界点 j
    int pi = partitionHoare(nums, left, right);

    // 左半部分的元素个数（[left, j] 包含的元素数）
    int leftSize = pi - left + 1;

    // 判断第 k 小在哪边
    if (k <= leftSize)
    {
        // 在左边找[left,pi]，k 不变
        return quickSelect(nums, left, pi, k);
    }
    else
    {
        // 在右边找[pi+1,right]，k 要减去左边已有的元素个数
        return quickSelect(nums, pi + 1, right, k - leftSize);
    }
}
```
