

核心思想：将数组分为三个区域，i左边是排序好的，i位置上的准备插入到排序好的部分的元素，i右边是未排序的。每轮都从i上取元素与i左边部分比较，直到找到不大于key的元素，在它后面插入。  

①每当遇到某个位置的元素是大于key的，j在处理完后都会移动到它前面一位，所以当处理完最后一个大于key的元素，k就在这个位置的前面一个，但这个元素后移之后原本的位置就是key将插入的位置，因此j+1就是要插入的位置  
  
在线算法，可以边接收数据边排序（如实时排名系统）  
```cpp
void insertionSort(vector<int> &nums)
{
    int n = nums.size();

    // 第一个元素默认有序，从第二个开始插入
    // i左边是排序好的，i位置上的要插入的元素，i右边是还没排序的
    // 每轮拿出i来跟左边的逐个比较，直到遇到key大于某个值，就在它后面插入
    for (int i = 1; i < n; i++)
    {
        int key = nums.size(); // 要插入的元素
        int j = i - 1; // 已排序区域最后一个元素

        // 在已排序区域从后往前找插入位置
        // 把所有比key大的元素都后移一位，因为key插入后所有元素都要后移
        while (j >= 0 && nums[j] > key)
        {
            nums[j + 1] = nums[j]; // 把位置j的元素移到位置j+1
            j--; // 移动完之后j往前继续检查
        }

        // j+1就是要插入的位置
        nums[j + 1] = key;
    }
}
```
