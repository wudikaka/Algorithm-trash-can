
核心思想：让每个父节点>=它的两个子节点，不停把根节点(最大值)放到最后并且再排成最大堆，最后变成升序。  
  
- 补充：  
最大堆是每个父节点>=它的两个子节点     
最小堆是每个父节点<=它的两个子节点  
  
文字描述一遍思想执行过程：  
  
- 对于数组[a1,a2,a3,a4,a5,a6,a7,a8,a9,……]  
   
- 先建堆：差不多就是第一行1个元素，第二行两个，第三行4个，第四行8个，以此类推每个元素有两个分支，然后从数组的0下标开始把每个元素按顺序放到每行中，从上往下，从左往右，至此粗略的建堆完成。  
接下来要构建最大堆，从最后一个非叶子的节点(还有子类分支的节点)开始调整，将其与其两个子节点比较，若它小于自己的子节点中最大的那个，就交换位置，交换后，若这个节点变成了叶子节点(再无分支的节点)，就结束；否则继续与下面更大的子节点交换，直到交换到叶子位置。  
重复上述步骤，自后向前(从下向上，从左向右)逐个调整其他非叶子的节点，最终变成最大堆，即每个父节点都大于等于其两个子节点。  
  
- 后排序：取最前面的父节点(数组最前面的元素)和最后面的子节点(数组最后面的元素)交换，原本最前面的元素就是当前区间的最大值，交换到末尾，右边界向前缩小一个。  
这时堆又变了，这次从新的根节点开始，拿第一个非叶节点与其子节点比较，若它小于自己的子节点中最大的那个，就交换位置，交换后，若这个节点变成了叶子节点(再无分支的节点)，就结束；否则继续与下面更大的子节点交换，直到交换到叶子位置，这个其实就是重复上述步骤，只是在最大堆建立之后，每次去掉找出的最大值之后都直接从第一个非叶节点开始比较交换。  
右边界右边都是排序好的。  
  
- 公式（记住就行）：  
索引 i 的"左儿子" = i × 2 + 1  
索引 i 的"右儿子" = i × 2 + 2  
索引 i 的"爸爸" = (i - 1) / 2  
最后一个有儿子的"爸爸"索引 = n/2 - 1  
  
代码过程分析：  
- 调用时heapSort(nums)，heapSort函数：首先建堆，进入for循环，从n/2-1下标开始，是因为这个就是最后一个非叶子节点，heapify(nums,n,i)就是让有n个元素的数组中i下标处元素往下所有分支都变成父节点>=子节点。for循环下一次让下标往前一个，因为之前那个是最后一个非叶子节点，往前所有的节点都必定是非叶子节点，往前每个都执行一遍heapify，建成最大堆。往下还有个for循环，让堆顶元素(最大的)和堆尾元素(数组中最后一个)交换，缩小排序区间，因为交换后会让原本的最大堆性质改变，所以需要调用heapify(nums,i,0)，即长为i的数组，让0下标处元素移动到正确位置确保依旧是最大堆。  
- heapify函数：确保以i为根的树满足最大堆性质，就是从i往下延申的部分。具体实现步骤：公式："索引 i 的"左儿子" = i × 2 + 1;索引 i 的"右儿子" = i × 2 + 2;索引 i 的"爸爸" = (i - 1) / 2"，先假定一个表示最大值所在下标的largest，默认为父节点，这里最先从i开始，就默认为i，分别拿左右节点与其比较，若左/右节点大于它则更新最大值所在下标。若最大值所在下标更新过，则交换父节点和子节点元素，交换之后只保证了这一组父>=子，但下面没有，则对于更新后的子节点位置再次使用heapify。  
- 为什么heapify函数中交换元素位置后，只对交换了位置的子节点再次使用heapify保证满足最大堆，不对另一个使用？--- 最开始是从最后一个非叶子节点开始排的，所以轮到上面某个节点交换了之后，只是两个子节点其中一个性质变了，另一个还没有，所以另一个不用用heapify。
  
```cpp
// 向下调整：确保以i为根的子树满足堆性质
void heapify(vector<int> &nums, int n, int i)
{
    int largest = i;       // 初始化最大为根
    int left = 2 * i + 1;  // 左孩子
    int right = 2 * i + 2; // 右孩子

    // 如果左孩子存在且大于根
    if (left < n && nums[left] > nums[largest])
    {
        largest = left;
    }

    // 如果右孩子存在且大于当前最大值
    if (right < n && nums[right] > nums[largest])
    {
        largest = right;
    }

    // 如果最大值不是根，交换并继续调整被交换的子树
    if (largest != i)
    {
        swap(nums[i], nums[largest]);
        heapify(nums, n, largest);
    }
}

void heapSort(vector<int> &nums)
{
    int n = nums.size();

    // 建堆：从最后一个非叶子节点开始向下调整
    // 最后一个非叶子节点索引 = n/2 - 1
    for (int i = n / 2 - 1; i >= 0; i--)
    {
        heapify(nums, n, i);
    }

    // 一个个从堆顶取出元素
    for (int i = n - 1; i > 0; i--)
    {
        // 将堆顶（最大值）放到数组末尾
        swap(nums[0], nums[i]);

        // 调整剩余部分（前i个元素）为堆
        heapify(nums, i, 0);
    }
}
```
